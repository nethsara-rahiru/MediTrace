# Collecting the original medicine dataset

Target 30–50 actual packaged product variants available in Sri Lanka. There is no
fabricated initial catalog and no assumed NMRA barcode API.

1. Inspect the actual carton/bottle/blister and record its exact brand, strength,
   dosage form, manufacturer, pack size and printed identifier. Different pack
   sizes or strengths need separate records when their identifiers differ.
2. Retain collection evidence and an inspection date. Keep any photographs outside
   the repository unless permission and privacy considerations have been checked.
3. Cross-check ingredients and label text against packaging, manufacturer
   documentation or other appropriate authoritative sources. Cite the exact
   document/URL and access date in the source field.
4. Record country, category and local prescription classification only when a
   source actually supports them. Leave unknown fields blank.
5. Enter each product through Add Product. Keep it user-entered until an actual
   independent review process exists. A photograph or barcode does not prove
   authenticity.
6. Scan the actual package again, check the exact offline match and confirm that
   another strength/pack is not accidentally matched. Document ambiguous cases.
7. Add owned stock separately, using its own batch and expiry. Do not turn batch
   details from one specimen into product-wide facts.

The blank worksheet is a collection aid, not an importer. The app currently
supports registration through its form. Include source references for ingredient
strength units/concentration basis and avoid copying long copyrighted reference
text without checking reuse permissions.

RxNorm/RxNav, openFDA and DailyMed may help with US terminology or labels, but are
not established Sri Lankan barcode lookup services. Online integration remains
outside release one and requires a separate coverage/licensing investigation.
